# Holo Music

Лёгкий музыкальный плеер для Android в стиле Holo Dark (Android 4.x). Без Material Design, без сторонних библиотек — только стандартный Android SDK.

![minSdk](https://img.shields.io/badge/minSdk-16-blue) ![targetSdk](https://img.shields.io/badge/targetSdk-29-blue) ![license](https://img.shields.io/badge/license-MIT-green)

## Статус

Бета. Основной функционал работает и протестирован вручную на нескольких устройствах (Android 9, Android 11+), но полного покрытия по прошивкам/версиям нет. Баг-репорты приветствуются.

## Возможности

- Библиотека: все треки, альбомы, исполнители — сканирование через `MediaStore`
- Плеер: очередь, честный shuffle без повторов, повтор (один/все), избранное
- Плейлисты: создание, удаление, добавление/удаление треков
- Ограничение библиотеки конкретными папками (в т.ч. SD-карта)
- Боковое меню с настраиваемым порядком и видимостью разделов
- Мини-плеер, персистентный на всех основных экранах
- Уведомление с `MediaSession` (обложка, управление, прогресс на новых Android)
- Контекстное меню трека: играть следующим, добавить в очередь/плейлист, перейти к исполнителю, сведения о файле (битрейт, размер), поставить на звонок, удалить
- Полностью на голом Android SDK — ноль сторонних зависимостей

## Пока не сделано

- Более широкое тестирование по устройствам/прошивкам

## Требования

- minSdk 16 (Android 4.0+)
- Java 8, без AndroidX/support-библиотек
- Разрешения: доступ к аудио (`READ_MEDIA_AUDIO`/`READ_EXTERNAL_STORAGE`), опционально «доступ ко всем файлам» на Android 11+ для просмотра SD-карты и запись настроек для установки рингтона

## Сборка

Обычный Gradle-проект, открывается в Android Studio или через `gradlew assembleDebug`. Сторонних зависимостей нет.
